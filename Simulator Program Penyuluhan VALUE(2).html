Pendahuluan

Value Penyuluh membantu Penyuluh Agama Islam merancang program berbasis VALUE yang berangkat dari kebutuhan nyata kelompok binaan. Isi identitas penyuluh dan data kelompok binaan terlebih dahulu, kemudian identifikasi masalah, tentukan kebutuhan, dan susun rancangan program. Hasil rancangan program merupakan draf awal yang perlu divalidasi sesuai kondisi lapangan.
