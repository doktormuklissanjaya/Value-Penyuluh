# Value-Penyuluh
Aplikasi ini menggunakan metode VALUE untuk membantu Penyuluh Agama Islam menyusun perencanaan program secara sistematis, terarah, dan terukur serta menyiapkan hasil perencanaan sebagai bahan pelaporan kinerja melalui EPA dan SKP Penyuluh.  Pencipta Metode VALUE: Dr. Muklis Sanjaya, S.H.I., S.Sos., M.Pd.
